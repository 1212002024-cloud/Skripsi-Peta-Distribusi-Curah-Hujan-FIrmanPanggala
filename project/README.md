# QGIS Project

Folder ini berisi file proyek Quantum GIS (QGIS) yang digunakan dalam penelitian.

Proyek QGIS digunakan untuk:
- mengolah data titik stasiun;
- melakukan interpolasi Inverse Distance Weighted (IDW);
- menghasilkan raster interpolasi;
- membuat garis kontur;
- dan menyusun visualisasi peta hasil penelitian.

Versi QGIS yang digunakan dalam penelitian adalah QGIS 3.38.0-Grenoble.
