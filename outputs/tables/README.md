# Tables

Folder ini berisi tabel hasil pengolahan dan analisis penelitian.

Tabel yang akan disimpan meliputi:

- Data curah hujan pada stasiun pengamatan.
- Perbandingan curah hujan Oktober 2020 dan Oktober 2025.
- Ringkasan hasil interpolasi.
- Data atau tabel yang digunakan untuk mendukung analisis penelitian.

Tabel disusun untuk memudahkan pemeriksaan dan reproduksi hasil penelitian.
