# Maps

Folder ini berisi peta dan visualisasi spasial hasil penelitian.

Output utama yang akan disimpan dalam folder ini meliputi:

- Peta lokasi stasiun pengamatan.
- Peta distribusi spasial curah hujan Oktober 2020.
- Peta distribusi spasial curah hujan Oktober 2025.
- Peta hasil interpolasi Inverse Distance Weighted (IDW).
- Visualisasi hasil analisis dan validasi.

Setiap peta akan dilengkapi dengan keterangan mengenai data, periode, metode, dan interpretasi hasil.
