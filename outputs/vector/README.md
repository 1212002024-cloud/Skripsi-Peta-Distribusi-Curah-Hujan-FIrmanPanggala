# Vector

Folder ini berisi data vektor hasil pengolahan spasial penelitian.

Data vektor dapat mencakup garis kontur curah hujan dan data spasial lain yang dihasilkan dari proses analisis menggunakan QGIS.

Garis kontur digunakan untuk membantu menggambarkan pola distribusi spasial curah hujan berdasarkan hasil interpolasi IDW.
