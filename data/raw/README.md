# Raw Data

Folder ini berisi data sumber penelitian sebelum dilakukan pengolahan.

Data utama penelitian berasal dari lima stasiun pengamatan BMKG:
- Manokwari Selatan
- Rendani
- Seigun
- Torea
- Utarom

Periode data yang digunakan adalah Oktober 2020 dan Oktober 2025.

Data pihak ketiga tetap mengikuti ketentuan penggunaan dari sumber data masing-masing.
